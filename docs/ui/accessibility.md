## Accessibility Guidelines

- Provide visible focus states on interactive controls (e.g., `focus-visible:ring`).
- Use semantic headings in lesson pages (`h1` for title; `h2`/`h3` in content blocks).
- Ensure sufficient color contrast; orange accent is paired with white/neutral backgrounds.
- All interactive icons (e.g., favorites) must have `aria-label`.
- For dialogs and mobile drawers, set appropriate `role` and `aria-modal`.

See `src/components/**` for examples.
