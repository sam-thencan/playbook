## Styling Guidelines

- **Brand**: Orange accent `#FF6A00`, neutral backgrounds, white cards, radius `10px`.
- **Font**: Poppins via `next/font` with CSS variable `--font-poppins` used as `--font-sans`.
- **Tailwind v4**: tokens defined in `tailwind.config.ts` and `src/app/globals.css`.
- **Accessibility**: Ensure focus rings (`focus-visible:ring`), semantic headings, and keyboard navigation.

See components in `src/components/**` for examples.
