## Glossary

- **RLS**: Row‑Level Security; database‑enforced access control per row.
- **SSR**: Server‑Side Rendering; Next.js renders on the server using user session cookies.
- **Service Role**: Supabase key with elevated privileges; use server‑only.
- **Perk/Offer**: Unlockable benefit based on day or completion percent.
- **Lesson Block**: JSON segment of a lesson body (`paragraph`, `heading`, `list`, `image`, `video`, etc.).
